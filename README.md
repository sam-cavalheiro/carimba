# Carimbá

Você é um gambá que caiu em um prédio, e agora sai carimbando tudo que vê pela frente! Inclusive, convenientemente, você sai aprovando leis!

O jogo ainda está em fase de prototipação e testes.

Jogo feito para FelpoJam 2026. Feito com [Godot](https://godotengine.org/).
